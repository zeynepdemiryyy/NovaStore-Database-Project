# 🛒 NovaStore E-Ticaret Veri Tabanı ve SQL Analiz Projesi

Bu proje, bir e-ticaret platformunun veri tabanı mimarisini, ilişkisel bütünlük kurallarını (PK/FK/CHECK Constraints) ve ileri seviye SQL sorgularını içermektedir.

## 📌 Proje İçeriği
- **NovaStoreDB SQL Scripti:** Bütün tablo oluşturma, kısıtlayıcılar (Constraints), indeksler ve veri ekleme kodları.
- **Analiz Sorguları:** Stok takibi, müşteri ciroları, kategori bazlı satışlar ve tarihsel analizler içeren 6 adet SQL sorgusu.
- **Rapor & Dokümantasyon:** Tüm sorgu çıktılarını ve ER diyagramını içeren proje raporu.

## 🛠️ Kullanılan Teknolojiler
- **Veri Tabanı:** Microsoft SQL Server
- **Arayüz:** SQL Server Management Studio (SSMS)
- **Modelleme:** Relational Database Schema (ER Diagram)
